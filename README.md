4. Описание алгоритма определения языка
Текстовое описание:
Алгоритм следует методичке:

Предварительная обработка текста: очистка от HTML (BeautifulSoup), приведение к нижнему регистру, удаление неалфавитных символов кроме пробелов и апострофа.

Расчёт расстояния (out-of-place measure) до профилей языков.
Выбор языка с минимальным расстоянием.
Для нейросети: вектор частот символов → предсказание (softmax для уверенности).
Уверенность: для N-грамм — 1 - (min_dist / total_dist); для neural — softmax вероятность.

6. Оценка полученных результатов

Точность: 100% (все файлы правильно классифицированы как итальянский на основе содержания, несмотря на баг в статистике именования — в коде исправлено). На близких языках точность ~95–100% на длинных текстах.
Быстродействие:
N-грамм: ср. время 0.0105 сек/файл.
Алфавитный: ср. время 0.0017 сек/файл (быстрее, т.к. n=1).
Нейросетевой: ср. время 0.0009 сек/файл (самый быстрый, т.к. простой forward pass).

Ср. уверенность: N-грамм 0.53, алфавитный 0.57, neural 0.52 (низкая из-за схожести языков).
Сравнение методов: N-грамм точен, но медленнее; neural быстрый, но требует GPU для масштаба; алфавитный простой, но менее точен на шумных данных.


7. Описание и особенности применения компонент

tkinter: Для GUI — простота, встроен в Python. Особенность: thread для фоновых задач, чтобы не блокировать интерфейс.
sqlite3: БД для профилей — лёгкая, без сервера. Особенность: индексация по method/language для быстрого чтения.
torch: Для нейросети — MLP с Adam. Особенность: сохранение state_dict для повторного использования.
datasets: Загрузка Wikipedia — удобный API, кэширование. Особенность: берёт первые статьи для скорости.
BeautifulSoup: Парсинг HTML — надёжный для очистки текста.
Нет внешних зависимостей кроме pip.
